# Sterling Custom Upholstery

Modern Next.js rebuild of [sterlingcustomupholstery.com](https://www.sterlingcustomupholstery.com/) for Jed's website-rebuild portfolio.

## Stack

- Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui

## Local development

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43167](http://127.0.0.1:43167).

## Pages

- `/` - Home
- `/why-upholster` - Why reupholster
- `/about` - Who we are / services / process
- `/portfolio` - Before-and-after gallery
- `/fabrics` - Fabric collections
- `/contact` - Showroom, hours, estimate form
